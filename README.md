# Admixing of antibiotics and antifungals in cement and Stimulan

**Working reference — Draft v2.0 (October 2026)**

A single-file, offline-capable web reference on adding (admixing) antibiotics and antifungals to PMMA bone cement and calcium sulphate carriers (Stimulan, Cerament) for periprosthetic joint infection (PJI).

> ⚠️ **Not approved for clinical use.** This is a working reference for protocol development. Doses, mixing steps and setting times are drawn from published evidence, project documents and manufacturer/practical charts; where sources disagree the disagreement is shown. Every regimen must be reviewed by your PJI MDT (orthopaedics and ID/microbiology) and pharmacy/DTC and checked against the SmPC and local policy. Admixing creates an unlicensed product.

## Contributing

Corrections, new evidence and dose clarifications are welcome as GitHub issues or pull requests. Please cite the primary source (DOI/PMID) for any dose, elution or safety statement.

## Evidence grading

A = RCT / systematic review · B = prospective cohort / registry · C = retrospective cohort / case series · D = in vitro / biomechanical / animal · E = expert opinion / case report / manufacturer data.
